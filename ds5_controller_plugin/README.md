# ds5_controller: بلغن GoldHEN لتشغيل يد PS5 (DualSense) على PS4

بلغن `.prx` يشتغل مع GoldHEN، يقرأ DualSense من منفذ **USB** ويحوله لصيغة يد PS4 (DS4)، فالألعاب تتعرف عليها.

مبني فوق مشروع xbox_controller_plugin (رخصة MIT، محفوظة بملف `LICENSE`)، وأضفت عليه دعم DualSense.

## الحالة بصراحة

- **مو مجرّب على PS4 حقيقي.** كتبته وفحصت منطق الترجمة بـ 46 اختبار على الكمبيوتر، وفحصت صياغة الكود مع هيدرات OpenOrbis، بس ما جرّبته على جهاز.
- شكل تقرير DualSense (مواقع الأزرار والعصي واللمس) مأخوذ من معرفتي بمواصفات الـ USB report المعروفة (نفس درايفر لينكس)، فإذا شي ما اشتغل صح، أول شي نراجعه هو هذا.
- **البلوتوث مو مدعوم.** هذه النسخة USB فقط (بكيبل).
- ما أكدر أبني لك ملف `.prx` من البيئة اللي اشتغلت بيها لأن أدوات OpenOrbis الجاهزة محجوبة عندي. البناء يصير بخطوة وحدة (تحت).

## شنو يشتغل

| على اليد | يصير على PS4 |
|---|---|
| X / O / مربع / مثلث | نفس الأزرار |
| L1 / R1 | L1 / R1 |
| L2 / R2 (تناظري + رقمي) | L2 / R2 |
| العصي + الضغط عليها | العصي + L3 / R3 |
| الأسهم (D-pad) | الأسهم |
| Create | Share |
| Options | Options |
| ضغط التاتش باد | ضغط التاتش باد |
| لمس التاتش باد (إصبعين) | لمس التاتش باد |
| زر PS | حسب `guide_action` بملف الإعدادات (الافتراضي: ضغط التاتش باد) |
| الاهتزاز | يشتغل (محرّكين) |
| Mute | غير مربوط (ما له مقابل على PS4) |

**ما يشتغل بهذي النسخة:** الجايرو وحساس الحركة (يرجع قيم محايدة)، التريغر التكيفي (adaptive triggers)، اللايت بار، سماعة اليد. لتجربة الحركة غير المعايرة ابنِ بـ `-DDUALSENSE_PASS_MOTION=1` (غير مفضّل).

## البناء (أسهل طريقة، بدون ما تنصّب شي)

1. سوّ ريبو جديد على GitHub وارفع محتويات هذا المجلد كلها.
2. روح لتبويب **Actions** → **Build ds5_controller.prx** → **Run workflow**.
3. بعد دقائق نزّل الـ artifact باسم `ds5_controller` (فيه ملف `ds5_controller.prx`).

> ملف البناء (`.github/workflows/build.yml`) يستخدم صورة Docker الرسمية مال OpenOrbis، **وما جرّبته**. إذا فشل، ارسل لي نص الخطأ من تبويب Actions ونصلحه.

بديل: على لينكس أو WSL بعد ما تنزّل OpenOrbis Toolchain: `make OO_PS4_TOOLCHAIN=/مسار/الأدوات`.

## التنصيب على PS4

1. شغّل الجيلبريك وحمّل GoldHEN (الجيلبريك مؤقت، يختفي بإعادة التشغيل).
2. انسخ `ds5_controller.prx` عبر FTP إلى `/data/GoldHEN/plugins/`.
3. افتح `/data/GoldHEN/plugins.ini` وأضف (انظر `plugins.ini.example`):

```
[default]
/data/GoldHEN/plugins/ds5_controller.prx
```

4. اختياري: انسخ `ds5_controller.ini.example` إلى `/data/GoldHEN/ds5_controller.ini` وعدّل الإعدادات.
5. وصّل اليد بكيبل USB بعد ما تشتغل اللعبة (أو قبلها)، وراح يطلع إشعار "DualSense connected".

## إذا ما اشتغل

أرسل لي ملف السجل `/data/GoldHEN/ds5_controller.log` وأقول لك وين المشكلة. السطر المهم يبدأ بـ `Pad detected & opened` وفيه VID/PID والـ endpoints.

## اختبار الترجمة على الكمبيوتر

```
bash tests/run_tests.sh
```

يحتاج clang فقط.

## ملاحظات

- ملف الإعدادات واسم السجل وملف IPC تغيّرت أسماؤها (`ds5_*`) حتى ما تتعارض مع بلغن Xbox إذا كان منصّب.
- الأيدي الثانية (Xbox 360/One، Switch Input-Only) تبقى مدعومة من الكود الأصلي، بس ما اختبرتها.
- بعض أسطر الإعدادات والتعليقات القديمة ما تزال تذكر "Xbox" لأنها من المشروع الأصلي.
